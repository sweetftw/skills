# skills

Prompts de sistema da Bytech, publicados para serem consumidos por automações via URL raw.

| Arquivo | O que é |
|---|---|
| [`automacao-logistica-diaria/prompt-curadoria.md`](automacao-logistica-diaria/prompt-curadoria.md) | Curadoria e redação do resumo diário de logística e transporte de cargas no Brasil |

## Por que isso é público

Uma automação baixa estes arquivos por URL raw a cada execução. Isso permite ajustar o
tom e as regras editando o arquivo aqui, sem tocar na automação — mas só funciona com
repositório público.

**Este repo contém apenas prompts.** Configuração, credenciais e a definição das
automações ficam fora daqui. Nunca commite chave de API, token, ID de grupo ou export de
workflow neste repositório.
